# NK60 macOS 配置实施计划

**目标**：为 NK60-V1 和 NK60-V2 交付可持久化的 macOS 键位、媒体和系统快捷键。

1. 用主机测试覆盖媒体报告、通用按键组合和释放顺序。为键盘引擎补齐映射和释放处理。
2. 接通 USB Consumer Control 描述符和报告，并测试普通键与 Consumer 报告共享端点和重连。
3. 通过 JSON 数据源及 Python 打包器生成 NK60-V1 和 NK60-V2 的 macOS 配置。主机回归通过现有配置加载接口读取两种板型的文件。
4. 扩展动作登记和分页，接通 `config_select` 的目标绑定和后台加载，覆盖持久化和目标冲突。
5. 运行主机回归、架构边界检查和板级构建，提供安装命令。
